# Trybunał Konstytucyjny AI

Hobbystyczna strona, która ocenia ustawę (PDF/DOCX) względem Konstytucji RP przy użyciu API Gemini.
To szacunek AI, nie opinia prawna ani orzeczenie Trybunału.

## Uruchomienie
1. Wygeneruj darmowy klucz w Google AI Studio (https://aistudio.google.com/apikey).
2. Otwórz `index.html` w przeglądarce.
3. Wklej klucz w polu na stronie (zapisuje się tylko w twojej przeglądarce; nigdy nie wpisuj go do kodu ani repozytorium).
4. Wgraj plik ustawy.
